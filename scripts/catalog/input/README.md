# Saved catalog pages

The catalog site blocks automated downloads, so save pages from your browser into this folder
(Chrome: Cmd+S / Ctrl+S, Format "Webpage, HTML Only"). The script reads them from here.
The HTML files are not committed (see .gitignore); only the JSON in src/data/catalog/ is.

Pages to save (2026-2027 Undergraduate Catalog):
- economics-bs.html: Economics, B.S. program page
- <subject>-courses.html: Course Descriptions filtered by prefix (e.g. econ-courses.html), with descriptions expanded
